# Documentation

The published contract lives in this directory: policy reference, adapter support, threat model, error codes, and release notes. Treat those documents as the source of truth for policy semantics, adapters, query vocabulary, audit behavior, and public APIs.

## Current status

Read policies, trusted Django request context, scoped QuerySets, the
django-mcp-server adapter, cumulative export budgets, and privacy-safe audit
metadata are implemented. A PyPI release is coming soon. Until then, install
from the GitHub repository; see the README.
